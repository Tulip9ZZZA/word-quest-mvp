# Word Quest Data Attribution

## Independent 5,000-word capacity index

The file `client/src/data/vocabulary.ts` is generated by `scripts/generate_word_index.py` using **wordfreq 3.1.1**. It is an independent English frequency index, not an Oxford 3000 or Oxford 5000 reproduction.

> Generated word-index data is shared under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). The application source code is separately available under the MIT License.

The attribution requirements recorded by wordfreq apply to this data. Word Quest credits **Robyn Speer** (the name required by wordfreq’s notice), along with the notices for **SUBTLEX** authors, **OpenSubtitles**, Google Books Ngrams, Wikipedia, ParaCrawl, and the Leeds Internet Corpus as described in the [wordfreq NOTICE](https://raw.githubusercontent.com/rspeer/wordfreq/master/NOTICE.md).

## Oxford reference

Word Quest links learners to the official [Oxford 3000–5000 word-list page](https://www.oxfordlearnersdictionaries.com/us/wordlists/oxford3000-5000) as an educational reference point. Oxford University Press has not endorsed Word Quest. The app does not bundle, reproduce, extract, or claim to provide Oxford’s curated word lists or PDF content.

## CEFR statement

Any CEFR-related label in Word Quest is an **app-generated vocabulary-coverage estimate** derived only from learner activity in this independent 5,000-word index. It is not a CEFR test, certification, diagnosis, or statement of overall English ability.
